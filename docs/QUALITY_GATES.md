# Типовые ворота качества SEO-конвейера

Краткий список типовых сбоев и проверок. Без клиентских имён и сайтов. Полный контракт — [../AGENTS.md](../AGENTS.md) и [../MINI_PRD.md](../MINI_PRD.md).

| Ворота | Типовой сбой | Проверка |
|---|---|---|
| Источники и права | Выдержку источника передали в модель вопреки запрету | При прямом запрете ИИ исключи источник из досье и генерации, найди другой. При неясных правах не передавай текст и пометь `needs_review`. |
| Факты | Точный claim держится на вторичном пересказе | Подтверди claim первичным источником: число, формулировку, дату. |
| Законы и нормы | Нет юрисдикции и редакции | Укажи юрисдикцию и дату редакции. |
| Метаданные | title/description/OG обещают отсутствующее содержимое | Метаданные описывают только то, что реально есть на странице. |
| CTA | Конечная точка после редиректов не совпадает с обещанием | Пройди все редиректы и сверь фактическую страницу с обещанным действием. |
| Ссылки | Обещан документ по ссылке, которого там нет | Проверь, что файл действительно доступен по ссылке. |
| Данные спроса | Частотность перенесли на другую тему | Используй переданные данные с датой и областью действия; иначе `not_checked`. |
| Платный сбор | Запустили новый платный сбор при запрете владельца | Соблюдай запрет владельца; используй только переданные данные. |
| Изображения: стиль | Серия фото без единого стиля | Зафиксируй style lock бренда и передавай его во все кадры серии. |
| Изображения: размер | Реальный размер файла или OG не совпадает с заявленным | Проверь фактический размер и итоговый OG. |
| Изображения: подпись | Видимая подпись генерации при запрете владельца | Убедись, что нет подписи генератора и водяного знака. |
| Партия | Публикация продолжилась после первого блокера | Останови партию на первом блокере. |
| Read-back draft/publish | Черновик или публикация считаются успешными по HTTP-коду без сверки записи | Прочитай ту же запись по стабильному ключу и сравни её с входом: статус, slug, заголовок, тело/контент, обложка и OG-изображение. Любое расхождение возвращает `failed` со списком полей. |
| Предпросмотр: изоляция | Preview изменил рабочие данные или раскрыл приватный вывод наружу | Запусти preview на отдельной копии базы и контента. Вывод держи приватным. Исходные данные оставь без изменений. |
| CLI: путь вывода | Ожидаемая ошибка пути вывода вернула стек-трейс, а очистка удалила чужой файл | На ожидаемую ошибку пути верни машинный код без стек-трейса. Очистка удаляет только созданный вывод и не трогает другой существующий файл. |

Автоматическая оценка не заменяет ручное решение. `pass` невозможен без закрытия critical findings и без обязательных входов.
