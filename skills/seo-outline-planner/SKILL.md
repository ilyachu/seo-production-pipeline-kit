# SEO Outline Planner

План — контракт между стратегом и моделью-писателем. Он задаёт задачу секции, доказательства, запросы и бюджет, а не только список заголовков.

## Когда использовать

- Семантика, досье и бренд-бриф готовы.
- Нужно выбрать формат статьи и отдать письмо другой модели.
- Нужно разнести запросы без каннибализации и переспама.

## Вход

- `semantic.clusters`, `research.claims`, `brand`.
- Выбранный контентный угол и целевой объём.
- Существующие страницы сайта, чтобы не дублировать их интент.

## Контентные углы

Используй один главный угол и при необходимости поддерживающие: топ вопросов; решение боли; сравнение/альтернативы; критерии выбора; инструкция/чек-лист; ошибки и диагностика; кейс/доказательства; данные/изменения. Не смешивай все углы в одну статью без причины.

## Что делать

1. Сформулируй одну задачу страницы и основной интент.
2. Распредели кластеры по секциям; один запрос может поддерживать секцию, но не обязан становиться заголовком дословно.
3. Для каждой секции задай `section_goal`, `answer_first`, `keywords`, `claim_ids`, `link_slots`, `target_chars`. До шага перелинковки `link_slots` содержат цель ссылки, но не выдуманный URL/ID.
4. Сохраняй естественную иерархию H1 → H2 → H3. Количество заголовков определяется задачей.
5. Объём задавай в знаках с пробелами. Рабочая стартовая сетка: 3–6 тыс. для узкого ответа, 7–12 тыс. для обычного гайда, 12–20 тыс. для глубокого сравнения. Это эвристика, не фактор ранжирования.
6. Укажи модель-писатель как capability: следует JSON, пишет по-русски, соблюдает источники и лимит секции. Конкретное имя модели — заменяемый пример.

## Выход

В `outline`: `page_goal`, `primary_intent`, `angle`, `h1`, `target_chars`, `sections[]`, `model_handoff`, `excluded_topics`. `internal_link_ids` добавляет следующий skill после проверки реальных URL.

## Самостоятельный режим

Если нет досье/бренд-брифа, можно сделать черновой outline, но секции с фактами пометь `needs_research`, продуктовые секции — `needs_brand_input`.

## Режим конвейера

Читай только утверждённые semantic/research/brand. Передай план `seo-linking-editor` и `seo-article-writer`; после утверждения изменения структуры фиксируются отдельной ревизией.

## Проверка

- Каждая секция отвечает на реальную задачу и имеет бюджет.
- Claim IDs существуют в досье; link slots описывают назначение будущей ссылки без фиктивных URL.
- Нет повторяющихся секций и скрытой каннибализации.
- Сумма бюджетов близка к общему объёму и не требует механической обрезки.
