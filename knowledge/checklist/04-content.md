# 4. Контент

> **[📋 Назад к чек-листу](../README.md)**

---

## 🎯 Почему это важно

Контент — это то, ради чего пользователь пришёл на страницу. Поисковики становятся всё умнее в оценке качества: они понимают, ответила ли страница на вопрос полностью, задержался ли пользователь, вернулся ли он обратно в выдачу. Страница-полуответ («вода» на 300 слов там, где нужна инструкция на 3000) не только не ранжируется, но и тянет вниз весь сайт — Google фиксирует «неудовлетворённость» пользователя и может понизить site-wide. В эпоху AI (Яндекс Neuro, Google AI Overviews) полнота и авторитетность контента становятся ещё важнее: AI-модели выбирают источники, которые действительно глубоко раскрывают тему.

---

## ✅ Что проверять

- [ ] **Тема каждой страницы раскрыта полностью** — страница должна отвечать на вопрос пользователя исчерпывающе. Если это коммерческая страница «Ремонт квартир под ключ» — должны быть этапы, сроки, материалы, цены, гарантии, фото работ. Если информационная «Как выбрать кондиционер» — типы, мощность, площадь, сравнение брендов, таблица, FAQ.
- [ ] **Уникальные Title и Description для каждой страницы** — заголовок содержит ключевую фразу (ближе к началу), побуждает к клику (выгода, цифра, вопрос), укладывается в ~60 символов. Description — не более 160 символов, объясняет, что получит пользователь на странице, содержит CTA. Никаких шаблонных «Купить X в Москве недорого».
- [ ] **H1 один, уникальный, содержит основной ключ** — H1 ≠ Title. Заголовок H1 — это название страницы для пользователя. Title — это то, что видно в выдаче и вкладке браузера. H2-H3 отражают логическую структуру текста как оглавление.
- [ ] **Контент содержит фактуру, а не «воду»** — живые примеры, цифры, кейсы (было/стало), сравнения, таблицы, инструкции, FAQ, чек-листы, фотографии реальных работ. Каждый раздел что-то объясняет, а не просто занимает место.
- [ ] **Старые страницы (2+ года) обновлены или удалены** — устаревший контент (цены, законы, технологии, «актуально на 2022») сообщает поисковику, что сайт не поддерживается. Регулярный рефрешинг контента — один из самых ROI-позитивных SEO-приёмов.
- [ ] **Автор, источники, дата публикации видны** — EEAT (Expertise, Experience, Authoritativeness, Trustworthiness) — фундамент качества для Google. Страница должна показывать: кто написал, на основе какого опыта, когда опубликовано/обновлено. Особенно критично для медицинских, финансовых, юридических тем (YMYL).
- [ ] **Медиа-контент дополняет текст, а не висит для красоты** — изображения с alt-текстами, инфографика там, где проще показать, чем описать. Видео (с расшифровкой) для сложных тем. Каждый визуальный элемент должен нести смысл.
- [ ] **Внутренняя перелинковка связывает страницы по теме** — с коммерческой страницы ссылки на кейсы, с информационной — на коммерческую (и наоборот). Пользователь не попадает в тупик, поисковый робот проходит глубже.

## 🔧 Как проверить вручную

1. **CMS или карта сайта** — получи список всех страниц сайта (через админку CMS, sitemap или краулер). Для каждой страницы проверь: уникальный Title и Description, наличие H1, дату публикации/обновления.

2. **Search Console** → Эффективность → Страницы. Сортируй по кликам и показам. Смотри страницы с высокими показами, но низким CTR — проблема в Title/Description. Смотри страницы с высокими показами и низкой средней позицией — возможно, контент не отвечает на запрос.

3. **Яндекс.Метрика** — Вебвизор по конкретной странице. Смотри записи посещений: скроллят ли пользователи до конца, кликают ли по внутренним ссылкам, уходят ли сразу или читают. Глубина просмотра 10+ секунд — хорошо, 0-3 секунды — страница не отвечает на запрос.

4. **Редакторский ручной аудит** — открой топ-20 страниц сайта (по трафику). Прочитай каждую глазами пользователя: понятна ли структура, есть ли конкретика, хочется ли дочитать до конца. Если самому скучно — пользователю тоже.

5. **LLM-анализ страницы** — скопируй текст страницы в ChatGPT/Claude с запросом: «Оцени полноту раскрытия темы [X] по шкале 1-10. Чего не хватает? Какие подтемы не раскрыты?» AI-модель хороша в оценке полноты контента и поиске пробелов.

6. **Анализ конкурентов** — открой топ-3 страницы конкурентов по целевому запросу. Сравни со своей: объём текста, структура, типы контента (таблицы, списки, изображения), наличие FAQ, фото, кейсов. Твоя страница должна быть как минимум не хуже по полноте.

## ⚡ Типичные ошибки

- **Title скопирован с конкурентов** — «Купить X в Москве | Интернет-магазин Y» — таких 50 штук в выдаче. Пользователь не понимает, почему выбрать тебя. Title должен содержать УТП.
- **H1 отсутствует или задвоен** — на странице либо нет H1 вообще (бывает на лендингах и старых CMS), либо два H1 (из-за особенностей шаблона). Поисковик не понимает, о чём страница.
- **«Вода» вместо фактуры** — страница на 5000 слов, в которой нет ни одной цифры, примера, таблицы или конкретной инструкции. Пользователь уходит, AI-модель (Neuro/AI Overviews) не цитирует такой контент.
